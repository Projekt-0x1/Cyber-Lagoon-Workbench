# Foundry workshop scope

The Cyber Lagoon Foundry/Workbench is the construction workshop/factory for **AGI**. Nothing about the current implementation is sacred: Recipe IR, developmental representation, executor physics, memory layout, Network motifs, constructor laws and hardware lowerings may be replaced when a measured alternative better serves the target organism. The goal and the causal/epistemic firewalls are the constraints.

## Direction lock from project owner

- Primary objective: construct a continuing Adult with human-like cognition and GPT-class-or-better language competence as quickly as causally defensible. The workbench exists to design, alter and test that Adult; it is not merely a verifier for old architecture.
- The Adult must not become an LLM, transformer, prompt/completion service, pretrained-model wrapper, hidden transcript engine or semantic oracle. **But the Workbench may use frontier LLMs as explicit cognition emulators/oracles during prototyping.** They may imitate the thought, language, planning, repair, inquiry or internal decomposition we want AGI eventually to perform so mechanics can observe a target phenotype and sculpt candidate mathematics around it. This scaffold must be labeled, experimentally separable and progressively substituted/lesioned; it is never AGI capability evidence. Production cognition and every promoted public action must survive with the LLM scaffold absent and remain resident causal computation.
- Quantity is fundamental, but **quality of the offered deterministic building blocks comes first**. Do not equate cognitive quantity with literal cell count, cellular-automaton lattice size, or object-per-neuron simulation. The target quantity is useful causal computation: large numbers of interacting learned/developmental mechanisms, Networks-of-Networks, recurrence, history and body/world coupling. A better mathematical abstraction that produces more useful interaction per byte/work unit is preferred. Consumer-hardware lowerings exist to make that effective quantity feasible.
- Nothing implementation-specific is sacred. DirectGenome, Recipe IR, Network organization, developmental law, memory representation, learning/credit, constructor machinery, language architecture, scheduling, sparse/dense representation, Tensor/RT/state-space lowering and CUDA organization may all be changed, merged, removed or replaced when measured evidence supports a better Adult.
- Revision 12.1 and every architecture document are hypothesis/donor material, not a holy grail. Preserve protected causal lessons only while they survive falsification.
- Do not restore retired legacy merely for compatibility. Useful ideas must be re-expressed in the current strict design and re-earned.
- Foundry trials may be huge; resident cognitive structure must remain owned, reachable, reusable and resource-accounted. Scale is required; stranded structure is not.
- Foundry members are graph-native capability engineers. `docs/constitutional_dependency_graph.json` is read directly to select ready RED frontiers, expose blockers, attach reference evidence to the owning GitHub issue, improve node work scope, and immediately demote claims contradicted by live source. No parallel Foundry backlog may outrank the constitutional graph. RED -> GREEN still requires the node's named production contract and repository workflow.
- GitHub issues are the durable shared engineering log for useful research findings, architecture decisions, representation ports, simulator changes, unexpected deterministic/emergent effects, RED/GREEN receipts, measured state/work deltas, blockers and next falsifiers. Link the owning graph node, research note, relevant Genome/Network spec section and Workbench assay rather than creating a second status system in issue prose.
- Genome/Network changes must preserve the brain-spec documentation lineage. When relevant, read and update the functional interpretation/controls in `docs/architecture/human_connectome_to_gamma_seed_atlas_v0.md` and the current Target-v5 network source `docs/architecture/target_v5_final/sources/human_connectome_to_gamma_network_plan_v7.md`. These are biological/functional donors, not immutable silicon wiring; representation changes should improve them rather than silently detach the Workbench from the researched organism model.
- **Decision prerequisites (before architecture choice or implementation):** the hard minimum is (1) mechanism-specific primary grounding — how would a brain/organism do *this exact function*, translated into hardware ethology (no chatbot, LLM, token, or input/output ontology as the model of mind); and (2) an independent Sapolsky-style nested-causation pass — immediate state, recent contact, learned/developmental history, social/source context, body/resource/allostatic state, controllability/predictability, delayed consequence and recovery. After those two passes, preserve **research agency** and search broadly: materially relevant frontier competitors should be researched when they plausibly bear on the mechanism, especially when the owner nominates one, while papers from apparently unrelated fields are equally valid when they contribute a mechanism, falsifier, mathematical abstraction, scaling law, or hardware principle. Rich Sutton, LeCun/JEPA, Pim de Witte/General Intuition, DeepMind/world-model research, Chomsky/psycholinguistics, control theory, dynamical systems, developmental psychology, motivation/social research, mathematics and competitors are examples rather than a closed list. Record the comparison set chosen, what was `USED`, `REJECTED`, or `NO_RELEVANT_CONTRIBUTION`, and why. Robbins may nominate phenomena but has no evidence authority. Ideas nobody has tried usually cannot be cited as already-validated biology: ground the constituent functions and falsifiers, label the silicon combination a **novel synthesis**, and demand stronger intervention evidence. Do not invent a citation analogue for an unprecedented mechanism.
- **Research-function law:** the mandatory biological/behavioral lenses are functional, not anatomical. **Before an architecture decision and before implementation, every substantive cognition/mechanism change must complete two separate grounding passes:** (1) mechanism-specific primary grounding of how biological organisms/brains solve the exact functional problem—evidence integration, history, timescale, variability, competition, plasticity, consolidation, lesion/recovery and falsifying interventions—and (2) a Sapolsky-style cross-level causation audit across immediate state, recent contact, learned/developmental history, social/source context, body/resource/allostatic state, controllability/predictability, delayed consequence and recovery. If the proposed silicon mechanism is genuinely unprecedented, do not pretend the exact design is biologically grounded: ground its constituent functions/constraints/dissociations, mark the implementation as a **novel engineering synthesis**, and demand stronger interventions. Sapolsky supplies nested causation across immediate state, history, development, social context, body/resource state and multiple timescales; McEwen/allostasis supplies adaptive regulation/recovery; Berridge requires wanting/pursuit, liking/satisfaction, prediction/surprise and learning to remain dissociable; agency/learned-helplessness work requires action->outcome controllability and forbids global punishment from merely subsequent aversive events; intrinsic motivation must arise from endogenous regulation, uncertainty/unfinished prediction, novelty, competence, controllability, information seeking and finite resources rather than a host reward head. Chomsky/psycholinguistics is a structural-language falsifier for productive hierarchy, recursion, structure dependence and long-distance relations, never a license to install UG/Merge/tree labels. Rich Sutton contributes general experience-driven learning/search/prediction/planning and the Bitter-Lesson pressure against hand-authored tricks, **not LLM/transformer/token/next-token/backprop/RNN/standard-RL ontology**. Tony Robbins may nominate phenomenological targets around physiology/state, focus, language/reframing, confidence, values, goals and questions, but has zero mechanistic authority until primary research independently supports the function and the Workbench earns it. Preserve organism functions and falsifiers; delete biological imitation when a simpler silicon-native mechanism wins the same intervention battery.
- **Research-propagation law:** a grounded finding is incomplete until it changes the shared engineering authority that will govern implementation. Every substantial research receipt must name `issue`, `graph_node`, and `genome_network_disposition`; update/comment the owning GitHub issue or work pack, update the constitutional node's scope/dependencies/status hypothesis or evidence note when the finding changes them, and update Genome/Network functional specs when the finding is heritable/developmental. For acquired lifetime cognition, `NO_GENOME_CHANGE` is an explicit positive disposition: preserve the generic developmental/plasticity law in Genome and keep learned contents in the Adult. Research that stays only in a diary while issue/graph/Genome continue to demand a contradicted mechanism has not completed the decision gate.
- **Living-substrate translation law:** neuroscience terms such as “rest”, “default mode”, “activity-silent” or “latent” are measurement- and task-relative; they never mean that a living brain literally stops its intrinsic electrical, chemical, metabolic and regulatory activity. Preserve the evidenced causal distinction—such as content leaving focal decodable activity while a cue-reactivable trace remains—without importing mammalian maintenance costs as silicon theater. Silicon is not metabolically equivalent to brain tissue. AGI must remain one causally evolving organism between contacts, but recurrence, decay, resource competition and maintenance are implemented only when they change lawful futures or win measured byte/touch/latency/energy tradeoffs on the actual hardware.
- Language/cognition work obeys an **N+1 organism-level discourse ratchet**. Every substantive **language/cognition mechanism addition** must end with a measured visible organism-level language/discourse improvement over the immediately preceding shared baseline in the same continuing lineage, with all affected earned gates non-regressed. The gain must be fixed/predeclared and inspectable in public behavior—e.g. more precise reference, a clearer or better-timed clarification, stronger causal/explanatory structure, improved multi-turn continuity, better source calibration, correction/rephrasing after failure, longer coherent composition, world/body transfer into language, initiative or appropriate silence. "More fluent" or "sounds better" is not evidence, and a host-selected expected string is not a gain. **Pure representation, state-minimization, allocator, persistence, compiler, performance, or hardware refactors are the narrow economic exception:** they may preserve the complete phenotype instead, but must explicitly declare the refactor lane, win a predeclared measured state/work/latency/complexity target, and preserve future causal/update authority under the same intervention battery. The exception is invalid if the change introduces, removes, or changes an organism mechanism rather than only its representation/execution.
- **Cumulative shared-main capability law:** shared `main` is one evolving organism, so every already-landed or concurrently-integrated capability is part of the acceptance baseline. A mechanic may replace another mechanic's representation, but may not make a previously GREEN language/discussion capability RED, silently remove its causal controls, or narrow the phenotype just because the implementation owner differs. Before commit, re-read the live worktree and fetched shared history, identify overlapping capability assays, and run a union gate that includes both the new visible gain and all affected peer capabilities. A concurrent peer change is not "unrelated" when it changes the same Adult state/operator surface. Resolve the integration in place and preserve the stronger union; do not dismiss regressions as peer-owned.
- **Continuous-life curriculum law:** the language curriculum is not a training phase and a corpus is not a privileged offline training object. One designated Adult lives one append-only causal chronology. Text corpora, dialogue, questions, corrections, demonstrations, world events, silence, replay/consolidation periods and later held-out probes enter only as ordinary authenticated sequential inputs/consequences at their actual point in that life. There is no host-controlled train/inference switch, no context-window substitute for resident learned state, no rebirth/reset between curriculum stages, and no checkpoint selection after seeing later outcomes. Earlier experience remains part of the same Adult's causal history while later experience extends it; repetition is additional lived contact whose effect depends on current resident state, source/context, chronology, plasticity gates and consequence history. "Held out" means not experienced before that chronological point, not evaluated on a fresh model. Resident plasticity may locally gate itself, rest, replay, consolidate or retrieve without updating; continuous life does not mean every coordinate updates every tick. Same-Adult online learning, continual retention/revision, and lineage/Gamma optimization remain distinct claims. Canonical donors: `docs/audits/2026-07-21-online-learning-cognition-red-team.md` (OL1/OL2/OL6 and no external deployment freeze) and `docs/architecture/target_v5_final/03_learning_language_knowledge_ecology.md` (developmental language preparation and causal closure).
- The shared Workbench is one **canonical shared `main` checkout/worktree** operated directly by frontier-model mechanics and checkpointed with frequent **exact-path atomic commits**, not blanket commits. Do not commit or push frontier work from a second clone, side seat, private worktree or alternate `main`; auxiliary seats are read/compute-only until their result is applied in the canonical checkout. Never use `git add -A`, `git add .`, `git commit -a`, or "commit all dirty files": the shared index/worktree can contain another mechanic's unfinished work. Commit only reviewed paths for one coherent result and push shared `main` regularly. Fetch before push only as a guard against accidental external publication. Any ahead/behind divergence between canonical `main` and `origin/main` is a synchronization fault: stop new frontier commits, preserve dirty work, merge the published history into the canonical checkout, rerun affected union gates and push the unified history. Never normalize divergent main lines, rewrite shared history, force-push, hard-reset/rebase away peer commits, or create private worktrees/branches merely to avoid collaboration.
- Xi/public salt is forbidden. Do not introduce a per-Adult seed/salt, public/action salt, salt-bearing identity root, renamed deterministic salt, or hidden symmetry-breaking value. Determinism comes from the actual causal state/executor; exact unresolved alternatives may remain unresolved. `b.deterministic_blank_birth` owns production removal.

The target is **one continuing AGI**, semantically the stateful mathematical organism described below. The Workbench is its design/construction source-semantics laboratory; Direct/CUDA is the current hardware biology backend and production proof target, not architecture authority or a second mind. CPU contracts, tiny CUDA capsules, Modal builds and focused language/quantity programs are falsification/qualification tools. A Workbench fixture never becomes a second cognitive authority merely because it is fast.

**LLM cognition-emulator law:** the Workbench may temporarily instantiate an explicit frontier-LLM scaffold that imitates a proposed AGI cognitive function at whatever level is useful—current thought trajectory, decomposition, uncertainty, inquiry, repair, planning, discourse, candidate internal variables or action policy. The point is to answer *"if the organism really had this function, what would it do and what intermediate structure would be useful?"* before spending time sculpting the resident mathematics. Treat the scaffold like a wind-tunnel model or oracle instrument, not like hidden production intelligence. Record its inputs/outputs and hypothesized internal functional decomposition, build resident mathematical challengers against that phenotype, then progressively lesion/substitute the scaffold. A Workbench result that still depends on the LLM is diagnostic only; the claimed AGI capability becomes eligible for promotion only after the scaffold is absent and held-out behavior, online learning, causal controls and continuing-state semantics survive.

**Whole-Adult operator law:** semantically, one developed Adult is one deterministic stateful mathematical operator over one continuing individual state: `(z_(t+1), output_t) = Phi_G(z_t, authenticated_input_t)`, where `G` is the content-free Genome/mechanism specification and `z_t` contains all individual-specific quantities required for lawful future behavior/learning. This does **not** require one matrix, graph, tensor, equation family or rewrite substrate. `Phi_G` may be factored into heterogeneous mathematics and lowered differently per factor; only the organism-level causality, composition, resource and evidence semantics must remain common. A representation replacement is legal only when intervention-equivalent future behavior **and future update authority** survive. Resident state is therefore necessary for a history-shaped Adult; permanent object graphs are not. Persist only future-causally sufficient learned/pending/body state plus exact evidence where authority still requires it, and rematerialize disposable cognition on demand.

**State-sufficiency / retirement law:** residency is temporal, not hereditary. A coordinate may be causal before a transition and spent immediately afterward. Observer diagnostics, exactly reconstructable Species/default structure, byte-identical duplicate evidence, and constructor/quorum variables whose admission transition is complete are presumptive deletion candidates. Every deletion assay must include a nearby negative control at the last point where the distinction is still causal, then prove post-transition future behavior and update authority are unchanged. Distinct episodes from the same source are not duplicates by default: timing, boundary context, withdrawal, ambiguity or later credit can preserve their authority.

**Active-interaction role law:** cognition is not a bag of independently dispatched learned relations. Current situations require transient mixed-rank interaction, recurrence, competition/reconvergence, boundary solving, prediction and composition among whatever learned/operator factors are causally recruited now. The historical `Network` object is one donor representation of that function, not a required primitive. A challenger may realize the same active closure with causal programs, state-space dynamics, sparse algebra, tensor/semiring structure or another mathematics if the interaction phenotype and interventions survive. Likewise, a historical `Recipe` is one donor representation of reusable learned relation/program function, not mandatory persistence ontology.

**Persistent/unfolded-state law:** persistent cognition is the smallest future-causally-sufficient learned/pending/body/evidence mathematics `z_t`; transient cognition is the bounded computational phenotype unfolded when that state meets current authenticated/endogenous participation and resources. Durable learned constructors/programs/relations may persist when they change lawful futures, but disposable active closures do not persist merely because they existed. Unfolding must be AGI-owned, deterministic from complete state, sparse/resource-charged, and must rematerialize current causal identities rather than replay stored activation, cached language bytes, a transcript, or a host-authored route. Checkpoints retain only future-relevant individual state plus exact evidence still required for authority—not settled disposable computation.

**Ephemeral language-activation law:** let `z_t` contain durable learned factors/evidence, let `O_t` denote current authenticated/endogenous participation, and let `B_t` be the current bounded resource envelope. An utterance-scale active computation is a fresh bounded unfolding `A_t = Unfold(z_t, O_t, B_t)`. A historical `Network` is one possible observer/implementation description of `A_t`, not required ontology. “Word”, “sentence”, and “parse” are observer descriptions of this transient computation, never persistent cognitive objects or host-selected routes. Each public byte must be a boundary transduction of `A_t` with exact ancestry. Settlement, withdrawal or expiry destroys disposable `A_t`; only future-relevant learned state, exact authority/evidence and an earned reusable factor/constructor may persist. A cached surface, transcript cursor containing future bytes, sentence ledger, or host-authored coupling is not this law.

**Language is an outer surface, not the model:** public language is one learned expression/action trajectory of the same multimodal resident ecology that also perceives, remembers, imagines, values and acts.  No word, language Network, transformer, semantic summary, or output adapter owns the underlying thought.  Nonlinguistic and mixed-modal closures must be able to form, compete, persist and alter action without first becoming text; language may later recruit and express part of that current closure through the sole public-byte path.

**Language-mediated construction law:** language/testimony may reshape the resident candidate frontier by nominating, predicting or helping construct nonlinguistic Recipes and Network closures.  A source-conditioned assertion may immediately create warranted resident belief and alter action when lived source/context relations support it; neither a host `trusted` flag nor the assertion itself supplies that authority.  Assertion, prediction and unfolded candidates are real participants and may earn ordinary credit for downstream causal effects, while circular self-confirmation remains forbidden.  Betrayal, error, missing access, ambiguity and world change must remain learnable competing explanations.  Required controls include context-specific reliability, near/far transfer, conflict, betrayal-like violation, recovery, copied-source dependence, withdrawal/reacquisition and lesion/sham.  After learning, a nonlinguistic relation should recruit when the teaching surface is absent where its remaining support warrants it.  Language that only creates more language fails this law.

**Cross-modal reactivation hypothesis:** persist sparse source-qualified relations and unfolding constructors, not image/audio files and not one monolithic person vector.  A partial current cue may recruit a bounded transient visual-, vocal-, episodic-, somatic- or language-shaped reenactment while preserving modality-specific differences, uncertainty and current resource pressure.  Primary studies find overlapping but distinguishable imagery/perception codes ([Lee et al., 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3288657/)), multimodal person responses to pictures and written/spoken names ([Quian Quiroga et al., 2009](https://pmc.ncbi.nlm.nih.gov/articles/PMC3032396/)), and face/voice identity structure at both single-neuron and population levels ([Tyree et al., 2023](https://pubmed.ncbi.nlm.nih.gov/37883535/)); these are phenotype hypotheses, not permission to install concept cells or pretrained semantic embeddings.  Raw or generated images/audio may enter only as provenance-preserving body contact, never as resident memory, labels, or answer routes.  Required controls include temporal offset, independently permuted pairing, single-channel contact, false completion/person confusion, invented-detail refusal, source withdrawal/reacquisition, focal versus remote-sham lesion, imagery/perception discrimination, and bounded retirement.

**Somatic-marker Network hypothesis:** interoceptive, resource, damage, repair and reafferent Occurrences may participate in the same transient closures and thereby alter attention, ambiguity resolution, learning eligibility and later language/action.  They are not a scalar sentiment/valence tag or authored reward route.  Bodily feedback has been linked to arousal and context-dependent intuitive decisions ([Dunn et al., 2010](https://pubmed.ncbi.nlm.nih.gov/21106893/)), and valence-specific expectations modulate heartbeat-evoked responses ([Marshall et al., 2018](https://pubmed.ncbi.nlm.nih.gov/30159945/)), but explicit contingency knowledge can also explain classic gambling-task behavior ([Maia and McClelland, 2004](https://pubmed.ncbi.nlm.nih.gov/15501919/)).  Promotion therefore requires an exact body-source -> resident-state -> pre-action arbitration -> action -> reafferent-consequence loop plus matched low/high body state, valence reversal, cost permutation, source withdrawal, lesion/sham, checkpoint and cross-modal language-transfer controls.

**Current reference ceiling:** opaque morphology IDs and ephemeral rematerialization are useful storage/execution experiments, not evidence of cross-modal binding.  A host call that chooses the joined Occurrences, source, effect or an `independent` boolean still authors the association and its credit; a host-authored entity-feature map or negative consequence still authors a somatic veto.  `reference_cross_modal_common_source_verify.py` is the fast hostile audit for this boundary: the present candidate is deliberately RED when congruent, temporally offset and deterministically mispaired streams can all be revised through the same host call, or when checkpoint credit/source evidence is rewriteable.  Promotion requires resident co-timing arbitration, exact authenticated consequence identity, causal-difference settlement, port/Occurrence ancestry, cascading withdrawal, authenticated checkpoint state and focal-versus-remote lesion discrimination.  A GREEN language-shaped or somatic-shaped fixture cannot override this ceiling.

**Parametric condensation law:** condensation that only replays one exact closure is compression, not yet an earned cognitive abstraction. Before promotion as reusable N+1 structure, the compact relation must preserve its exact lived witness while rebinding held-out boundary variables/Occurrences of the same learned relational shape. Higher-rank condensation should call already-earned lower-rank relations when that preserves the boundary law rather than flattening them. Contradiction/source drift must deopt or reopen the shortcut without erasing the lived closure.

**Quantity/storage law:** resident cognitive quantity may grow very large, but current computation must be incidence-local. Durable learned configuration/Network-revision populations are permitted to scale independently of hot closure width; an ordinary contact/expression may touch only the exact indexed candidates and causal rows it recruits. Rebuildable indexes are not authority and should be packed/pageable. Content-addressed roots may reference ordinary resident relation structure instead of duplicating that structure in a second semantic store.

In scope for the **current strict reference contract** are bounded numeric learned-state/relation semantics, resident arbitration, authenticated contact/action/consequence, ambiguity/refusal, causal-difference credit, complete checkpoint/replay, cascading source withdrawal, condensation/deoptimization and per-byte ancestry. This contract is an evidence donor, not permanent AGI ontology. Learned lexical/construction/discourse, planning, Genome/Life-Function mirrors, quantity and PyCUDA pressure remain separate research assays until they are expressed through source semantics without semantic host authority.

GPU scale claims are explicit: `pycuda_organism_scale_verify.py` requires the same learned language, eight-event discourse, reafferent repair, causal plasticity and learned two-step planning at 131,072, 1,000,000,000 and 80,000,000,000 procedural population sites with bounded life-delta state and touched work. `pycuda_language_pressure_verify.py` is V2-only and requires 16,384 lived lexical bindings, indexed first/middle/last retrieval and far-end public expression on the 80B namespace. These are scale gates, not general AGI or human-language mastery.

Out of scope for current GREEN claims: production Adult attachment, runtime LLM calls, prompts or semantic summaries, host selection of current thought, per-Recipe compilation, whole-state production IR translation, whole-Adult physical Direct parity, and human-level/AGI capability promotion.

## Quantity / population law

Human cognition is treated as a quantity phenomenon as well as an architecture phenomenon, but **quantity is not literal artificial cell count**. The 80-billion-neuron human scale remains a pressure/reference point for storage and execution economics, not a requirement to instantiate 80B cell objects or a claim that one Adult element equals one biological neuron.

The Workbench should measure effective cognitive quantity as independent finite axes rather than one population scalar. Candidate axes include active representational dimension, independently addressable learned distinctions, causally effective interactions per tick, recurrent depth, compositional width/depth, causally reachable history span, concurrently supported predictive alternatives, touched mathematical work, persistent learned description size, active materialized state size, held-out transfer and interference resistance. These measurements are provisional and may be replaced when better falsifiers exist; see `docs/research/foundry_mathematical_cognitive_quantity_grounding_2026-08-31.md`.

Existing reference axes remain independently charged where they are causally real: current Occurrence population, route/transport width, causal ancestry depth, physical terminal claims, public trajectory extent, frozen action closure and active compositional depth. Equal numeric values are allowed; one shared accidental bound is not.

`quantity_scaling_contract.py` protects the consumer-hardware model. For 80B simple states, one packed bit is about 9.3 GiB, two bits about 18.6 GiB and four bits about 37.3 GiB before connectivity/provenance/indices. Therefore the intended equivalent is heterogeneous: enormous packed/procedural cold matter plus sparse/tiled hot Occurrences and touched relation incidence. Object-per-neuron host records are explicitly not the plan. A 24 GiB device can address about 103B two-bit states in isolation, while only a small touched fraction should incur expensive execution in any tick.

The same logical Network may earn different physical lowerings. Current source inventory contains Tensor Core dense execution, selective state-space machinery, device-family queues, resident executable morphology and a paged sparse route bank. Explicit RT/BVH/OptiX execution is not present in the current sparse source inventory; it remains an optional spatial/incidence lowering to implement only if measured parity and resource benefit justify it. Tensor/RT/state-space/sparse are execution tools, never semantic authority.

## Authority law

The strict reference runtime accepts numeric contact/state only. It has no runtime transformer, host goal API, per-Recipe compiler or runtime install API. Independent consequence is necessary but not sufficient for positive causal credit; causal difference is required. Checkpoint/replay, source withdrawal, ambiguity and bounded resources are part of the reference semantics.

The former `foundry.py`, `reference_vm.py`, `full_loop.py`, authored symbolic organism, and their transitive tests were deleted together. They are not preserved as compatibility surfaces. Reintroduction requires a new strictly typed design that earns its place against the current contract.

Revision 12.1 and earlier architecture documents are hypothesis inputs to this workshop, not frozen implementation doctrine. Protected properties such as Recipe/Occurrence/Network separation, independent finite capacities, authenticated evidence and consumer touched-work scaling should be retained only while they continue to survive falsification.

**Engine-dissection law:** the Foundry advantage is mechanism-level replaceability, not categorical opposition to transformer-like computations. Any local mechanism may expose a transducer-like boundary or use mathematics also found in other AI systems. What matters is that cognition is factored into explicit causal mechanisms that can be isolated, lesion-tested, replaced, recomposed and re-lowered while preserving the continuing individual's earned state and interfaces. A superior memory, language/composition, recurrence, somatic, repair, developmental, solver or hardware mechanism should be able to replace its incumbent instead of requiring wholesale retraining of one opaque global function.

**Language integration law:** language is the highest-bandwidth external phenotype for whether the internal organism is actually integrating composition, memory, causal reasoning, body/world learning, source history, imagination, social state and developmental accumulation. Internal receipts are necessary but cannot compensate indefinitely for stagnant discourse. The expected direction is rapid N+1 improvement toward precise, grounded, history-sensitive human-like discourse, while surface fluency without corresponding organism causality is not progress.

## Organism / cognition law

The target is a continuing organism program, not a prompt-response chatbot. External simulation may deliver authenticated sensory/source/body/language contact and later consequences to actions that actually occurred. It must not call `answer`, `think`, `speak`, `enqueue_goal`, select a current Recipe, or provide a semantic summary of the desired cognition. Resident/endogenous work may continue across ticks from already-present causal state and consequence-gated continuation structure; terminal silence is valid behavior.

**Component-boundary / whole-organism law:** a local input/output assay is not evidence that the whole Adult is an input/output architecture. Receptors, language pathways, Recipes, Networks, motor pathways and other subassemblies may legitimately expose bounded `state/input -> output` behavior when dissected, just as an engine pipe has an inlet and outlet. Do not reject a useful component merely because its isolated assay looks transducer-like. The whole-Adult claim becomes RED only when the continuing system can be collapsed to a language-context-to-language-output responder whose relevant state is essentially the supplied linguistic context. Whole-organism language evidence must therefore include matched-current-input / different-lived-history arms; silent endogenous intervals whose later behavior depends on what occurred during silence; delayed consequence and revaluation; nonlinguistic/body/world acquisition later expressed in language; source/social/somatic/resource-history effects on discourse; warranted spontaneous inquiry/action without a fresh language request; and separately lived sibling Adults that share a canalized competence envelope without being required to emit identical answers. No random-output escape hatch is allowed: the same complete Adult state plus same ordered inputs and executor must replay exactly; diversity must be causally earned by different lived state/history.

Do not make semantic inner-state classes such as THOUGHT/BELIEF/IDEA into privileged runtime objects merely because observers use those words. What an observer may later call a thought must arise from ordinary resident relations, Occurrences, bindings, competing alternatives, recurrence, prediction, planning, source state, action preparation and consequence. Foundry/LLM authors may redesign those mechanisms freely; runtime language/cognition may not become an LLM or hidden transcript path.

Human/frontier-model language quality is an outward phenotype target, not an architectural permission slip. The workshop should improve language acquisition, lexical/distributed representation, syntax/morphology, reference/common ground, discourse, questions, epistemics, style and long-form prose through the same organism mechanics. Architecture Revision 12.1, neuroscience analogies and all current CUDA structures are hypotheses/donors only; preserve no legacy for compatibility when a better measurable mechanism exists.

## Fast-iteration law

Foundry is a workshop, so latency is a design variable. Do not put full-Adult CUDA rebuilds in the hypothesis inner loop. Use the cheapest execution surface that can falsify the current mechanism, then climb the parity ladder only after the mechanism survives.

1. **Reference/host discriminator:** milliseconds to seconds; no CUDA; use for Recipe/Network/state-law design and hostile controls.
2. **Tiny production-header CUDA capsule:** compile only the directly involved generic device headers when physical semantics matter; no full Adult link.
3. **Modal cached compile:** `tools/modal_gpu_build.py` is the default remote compilation lane for named CUDA targets from sparse Foundry seats. It uses persistent ccache and returns the real ELF. Sparse worktrees may omit optional top-level directories; compile mode must not fail merely because `.github/` or top-level `cmake/` is absent.
4. **GPU execution/sanitizer:** run the returned ELF on an actual GPU only after compile success. GPU time validates physical execution; it is not the place to discover ordinary compile defects.
5. **Full continuing Adult:** reserved for named integration gates such as #1610 S1-S5, checkpoint/replay, lived-world authority, and final graph promotion. Rebuild the Adult core only when the core itself changed.

A failed lower rung is sufficient to reject the candidate. A GREEN lower rung never promotes a higher claim. The workbench should therefore support thousands or millions of reference/capsule trials per occasional Adult parity run. Per-Recipe or per-Network CUDA compilation remains forbidden; only generic executor/substrate changes justify rebuilding the physical Adult.

**Nuisance-scale rule:** do not pay a large logical quantity in every assay when that quantity is not the tested variable. Sweep the fixture across a broad range; if the public phenotype, causal intervention traces and negative controls are invariant, use a conservative smaller fixture for the seconds lane and keep one separate named large-scale assay for the actual scale claim.
